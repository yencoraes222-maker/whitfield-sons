# Whitfield & Sons – landingspagina

Statische site (HTML, CSS, JS) voor GitHub Pages. Geen build-stap nodig.

```
index.html        de landingspagina
privacy.html      privacyverklaring (GDPR)
css/style.css     huisstijl, layout en animatie
js/main.js        videoknop + mobiel menu
assets/fonts/     Fraunces + Space Grotesk (lokaal, woff2, OFL-licentie)
assets/img/       beelden (webp + jpg)
assets/video/     ochtend.mp4 (Google Flow, gemonteerd) + poster
```

## Online zetten via GitHub Pages

1. Maak op github.com een nieuwe **public** repository, bv. `whitfield-sons`.
2. Klik op **Add file → Upload files** en sleep de **inhoud** van deze map erin (dus `index.html`, `privacy.html`, `css`, `js`, `assets`, niet de map zelf).
3. Klik op **Commit changes**.
4. Ga naar **Settings → Pages** → *Source*: **Deploy from a branch** → branch **main**, map **/ (root)** → **Save**.
5. Na 1 à 2 minuten staat de site op `https://<jouw-gebruikersnaam>.github.io/whitfield-sons/`.

## Na het publiceren

- Test het formulier met een testadres → kijk of je in de groep *newsletter* komt en MAIL 1 krijgt.
- Laat de knoppen in MAIL 1–3 in MailerLite naar `…/whitfield-sons/#staaltje` linken.
- Screenshots desktop + mobiel voor het verslag.
